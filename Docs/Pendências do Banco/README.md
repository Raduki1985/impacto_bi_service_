# Pendências do Banco

Pasta local, fora do Git (fica dentro de Docs). Um arquivo por pendência
do banco do SGI: algo que o BI não consegue resolver sozinho porque o dado
não existe, está incompleto ou é um risco. Cada arquivo diz o que falta,
o efeito no portal, o que fizemos enquanto isso e quem decide.

Nome dos arquivos: data em que a pendência apareceu e um título curto.
